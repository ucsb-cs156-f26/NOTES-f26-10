# Section 4.5: Ad-Hoc vs. Professional

Summary by Zhewen Jin

# Question 1
My experience in school is a mix of what the paper describes. In some of lower-devision programming classes, most assignments were focused on making the code work and passing the required tests. We did not spend much time thinking about how software is used in a real company. However, in my current higher-devision class, I have started to use tools and practices that are closer to industry. I use several tools, such as Git and GitHub, to manage code, use automated testing, and deploy applications to Dokku. As a result, my experience is a little different from some of the people in the paper since I have learned these skills in class, so I feel more prepared. 

# Question 2
The developers were surprised by how important professional software development practices are in industry, and they found that Git, version control, testing, and Agile methods were used much more often than they expected. Some developers said that they had little or no experience with Git before starting their jobs, even though companies use tools like GitHub to manage code, and they were also surprised by the amount of work needed to maintain real software. 
    
# Question 3
Students can prepare better by using professional tools, like Github, and practices while they are still in school, especially for group projects. Students should learn how to make commits, use branches, review changes, and work with other people on the same repository. They should also practice writing unit tests instead of only checking their programs manually. They can learn how automated testing helps find problems before code is deployed, which would be helpful to work on larger projects that maybe would continue for more than a few weeks. Practice deploying an application, fixing bugs, and maintaining it after it is released are also very helpful.
